pKa 机器学习教学工具

以有机酸 pKa 预测为例，用图形界面和五组渐进数据集教授特征工程与决策树。

用熟悉的化学问题学习机器学习

pKa-ML Education 面向化学本科教学，以有机酸 pKa 预测为例，通过图形界面介绍决策树、特征工程和模型泛化。学生可以在无需编程的情况下完成主要教学流程。

五组数据，逐步改进描述符

  • 从碳原子与羧基计数等基础描述符开始。
  • 引入卤素计数与更细的取代基描述。
  • 增加吸电子基团的位置和强度信息。
  • 比较模型在训练、验证和固定外部测试分子上的表现。

教学重点

学生通过调整决策树深度理解过拟合，通过树的分裂与特征重要性练习化学解释，并观察化学知识如何帮助特征设计。

获取与运行

Windows 用户可从 figshare 获取可执行文件。Python 用户可运行仓库中的 python DTcode/predictpka260324.py，依赖见仓库说明。

当前仓库包含源码与 dataset1.csv 至 dataset5.csv。相关教学稿件在仓库中标注为准备中，引用信息以其后续更新为准。
