在线计算

点击上方在线计算演示，用邮箱和密码注册，验证邮箱并等待管理员批准。在 GBLine 中上传 PNG 或 JPEG 图表（最多 10 MiB），填写可见曲线数及每条曲线的最大点数，提交一次即可。工作区提供可下载的双曲线示例。

工作区提供纯软件提取与 Qwen 辅助两种方式。站点模型服务配置完成且可用时，默认选择 Qwen 辅助：将图表图片发送到站点配置的模型服务，每张图最多复核两次，密钥和调用费用由站点统一承担，用户无需填写 API key。提交前会显示当前可用状态；模型服务未就绪时仍可选择纯软件。

完成后，在任务旁点击交互审核，将曲线叠加到原图上检查。可以选择、高亮或隐藏各条曲线，并进行缩放和修正：

  • 四点校准：X、Y 轴各点选两个刻度，填写实际数值，选择线性或对数尺度；支持反向坐标轴。
  • 从原始图片拾取曲线颜色，再按校准／拾色结果重新提取。新建任务占用正常任务配额，不调用 Qwen。
  • 橡皮擦只删除选中曲线的点，支持撤销。CSV 用 segment_id 保留断点，使用时不要跨段连接。
  • 保存“接受”“仍需修正”或“放弃”的审核版本。可以重新打开已保存的版本，下载曲线 CSV、叠加预览与审核记录。原始提取结果保留为单独下载，不被覆盖。

在线版本支持单面板、一组 X/Y 坐标轴。需要复核的结果不会冒充经过验证的数值曲线。人工校准与接受会明确记录为人工干预，不当作自动验证；模型复核也不能保证提取正确。

每项任务限制 2 个 CPU 线程、4 GiB 内存、5 分钟。各工具共用每用户 1 项运行、2 项排队、每天 10 次提交的配额。私人结果保留 72 小时。

GBLine 是面向科研折线图与化学谱图的本地数字化工具，将 OCR、坐标标定、像素曲线提取与可选的视觉大模型复核连接起来，通过 MCP 提供工具接口。

数值核心负责坐标换算与曲线追踪；视觉模型观察原图中的刻度和曲线颜色，提出修正，并根据工具返回的诊断继续复核。

主要工作流

  • 输入单面板图，检查绘图区、坐标轴与可见刻度。
  • 根据图像证据建立线性或 log10 坐标映射。
  • 提取曲线像素；工具要求时复核歧义刻度、漏检曲线或颜色。
  • 获取完整数值曲线和诊断记录，检查覆盖与数值质量后再用于分析。

MCP 接口包括 inspect_chart_axes、extract_chart_data 和 get_curve_full_data。根据证据情况，工具可以返回提取数据、请求继续复核，或明确弃权。

怎样判断输出可用

坐标轴正确、曲线数量符合预期，并不保证整条曲线已经恢复。需要检查横轴覆盖范围、断裂，以及提取结果与原图的重合情况。多面板图应先拆开；双 Y 轴及缺少足够可见标定证据的图不属于当前流程的适用范围。

当前研究包含开发性试验与回顾性验证，面向未见谱图的独立评价仍在推进。

获取方式与研究状态

当前网页适配器采用已选定的 qwen-assist-2 策略和 compact-review-3 证据校验。本地 MCP 实现也可搭配支持图像与工具调用的 Agent；数值核心不绑定某个模型服务。开发示例的表现不代表独立测试集准确率。
