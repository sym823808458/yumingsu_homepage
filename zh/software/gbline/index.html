从谱图图片到数值曲线

GBLine 是面向科研折线图与化学谱图的本地数字化工具，将 OCR、坐标标定、像素曲线提取与可选的视觉大模型复核连接起来，通过 MCP 提供工具接口。

数值核心负责坐标换算与曲线追踪；视觉模型观察原图中的刻度和曲线颜色，提出修正，并根据工具返回的诊断继续复核。

主要工作流

  • 输入单面板图，检查绘图区、坐标轴与可见刻度。
  • 根据图像证据建立线性或 log10 坐标映射。
  • 提取曲线像素；工具要求时复核歧义刻度、漏检曲线或颜色。
  • 获取完整数值曲线和诊断记录，检查覆盖与数值质量后再用于分析。

MCP 接口包括 inspect_chart_axes、extract_chart_data 和 get_curve_full_data。根据证据情况，工具可以返回提取数据、请求继续复核，或明确弃权。

怎样判断输出可用

坐标轴正确、曲线数量符合预期，并不保证整条曲线已经恢复。需要检查横轴覆盖范围、断裂，以及提取结果与原图的重合情况。多面板图应先拆开；双 Y 轴及缺少足够可见标定证据的图不属于当前流程的适用范围。

当前研究包含开发性试验与回顾性验证，面向未见谱图的独立评价仍在推进。

获取方式与研究状态

当前本地 MCP 实现的文档版本为 2.0.0。模型辅助需要支持图像与工具调用的 Agent 及所选服务；数值工具不绑定特定大模型平台。
