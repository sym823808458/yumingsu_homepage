GBLine · 图文使用指南

自动提取后把原图与数据重绘图并排核对，检查校准与曲线，再保存审核结果。

免费使用 · 线上体验软件介绍

截图来自公开教学数据或合成示例，不含用户账户、任务令牌或未公开研究数据。点击图片可放大。

1. 登录与任务状态2. 上传单张图表3. 并排核对原图与重绘曲线4. 保存审核版本与导出

1. 登录与任务状态

使用已批准的账户登录。新用户先注册并验证邮箱，管理员批准后才能提交计算。

各工具共用账户配额：同时1个运行任务、2个排队任务，每天最多提交10次；结果保留72小时，需要长期保留时请自行保存。

2. 上传单张图表

选择单个 X/Y 坐标系的 PNG/JPEG 图表，填写可见曲线数量及每条曲线点数，然后提交。图片最多10 MiB、2000万像素。

已批准用户共用服务器配置的千问接口，不需要填写 API key；模型输出仍需人工核对。

3. 并排核对原图与重绘曲线

处理后打开曲线审核，左边是原图，右边是提取数值重绘图。可分别勾选曲线、连线和选中曲线的采样点，点击点查看坐标。

“Inspect／编辑”选择当前曲线；校准、拾色和橡皮擦在原图操作。使用坐标前核对坐标轴、单位及线性／对数尺度。

4. 保存审核版本与导出

校准或擦除后先保存人工审核版本，再检查并导出 CSV。原始提取与人工审核版本明确区分。

勾选框只控制显示，不会裁剪导出的 CSV；擦除缺口保留为缺口。仅导出显示 SVG 不等于保存了审核数据。

遇到问题

review_required 表示证据不足，不能把数值曲线视为已确认，并不等于 CSV 丢失。先打开证据与审核界面；没有可用曲线时更换清晰裁图或重新提交，不要补造点。

失败时保留任务编号和提示。每次最多5分钟，并受共享账户配额限制。
