从一张底图到楼栋巡检概览

楼栋风压筛查工具是一个本地桌面软件原型，用于标注多栋建筑，并比较不同来风方向下的相对风压暴露。它将图像比例尺标定、楼栋轮廓编辑、层数与高度录入、简化风压估计和可视化导出连接在同一工作流中。

项目面向小区、校园和园区等多楼栋场景的探索性巡检规划，帮助整理在特定风情景下更值得进一步检查的楼栋、立面和楼层段。

当前原型已经具备的功能

  • 加载用户提供的底图，通过两个比例尺端点标定距离。
  • 创建和修整楼栋轮廓，支持角点编辑、增加顶点和旋转。
  • 记录楼栋名称、层数、高度，并设置目标楼栋。
  • 标注空旷区域，在方向性暴露估计中考虑周边楼栋。
  • 随风向变化比较立面风压、楼层段摘要和楼栋排序。
  • 使用 JSON 保存和恢复项目标注，导出静态 PNG、俯视 GIF 和伪三维楼层 GIF。

使用流程

准备一张底图和已知长度的参照物，完成比例尺标定。逐栋修整轮廓，录入层数或高度，并补充相关空旷区域。设置风速和来风方向情景，再查看楼栋总览，以及目标楼的立面和楼层段输出。

标注数据保存在原始图像的像素坐标中。缩放和平移只改变桌面视图，不改变已经记录的楼栋几何。

如何理解输出

当前模型以速度压为基础，结合高度、立面朝向，以及楼栋形状、周边暴露、遮挡、空旷区和近楼通道的经验修正，形成分立面、分楼层段的比较。楼栋高度分为四个区段，便于查看不同高度范围的相对差异。

伪三维动画展示的是简化筛查模型的表面风压估计如何随风向变化。颜色代表模型中的相对暴露程度，不是求解得到的空气流场，也不是现场损害测量结果。

适用范围与当前边界

该软件处于开发原型阶段。压力系数与环境修正包含经验假设，项目说明也指出仍需与实测及成熟工程方法进行比较验证。当前不估计玻璃破裂概率，不提供结构或幕墙安全认证，也不替代 CFD、风洞试验或专业工程评估。
