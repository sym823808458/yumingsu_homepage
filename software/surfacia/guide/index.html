Surfacia · Online modeling guide

Submit an existing descriptor table for fixed regression and signed SHAP explanations. The online route does not run quantum chemistry or molecular-surface generation.

Free online experienceSoftware overview

Screenshots use public teaching data or synthetic examples, without user accounts, task tokens or private research data. Select an image to enlarge it.

1. Access and task lifecycle

Sign in with an approved account. For a new account, register and verify your email; the owner must approve the application before computation is enabled.

All tools share per-account limits: one running task, two queued tasks and ten submissions per day. Results expire after 72 hours. Save results you need to keep.

2. Prepare the descriptor CSV

Use UTF-8 CSV with a continuous target column and 1–32 numeric descriptors, 30–500 samples, ≤2 MiB. No missing values, formulas or model files. Optional Sample Name identifiers must be unique; optional smiles are ignored.

Start with the downloadable 36-molecule public example. Its labels are calculated Crippen logP, not experimental measurements or a surface-descriptor benchmark.

3. Submit and inspect validation

Submit, retain the task ID, and wait for completion. The fixed XGBoost route uses all descriptors with 350 trees, depth 8, learning rate 0.03. Identical descriptor vectors stay in the same group; 20% of groups are held out, with grouped validation on the modeling pool.

This tool currently returns a result ZIP. Open README.txt and report.json, compare held-out errors to the training-mean baseline, and inspect parity.png. Poor or negative R² is a result to discuss, not hide.

4. Read signed explanations

shap_importance.png summarizes attribution magnitude; shap_dependence.png and shap_values.csv show direction. Positive SHAP raises this model’s prediction relative to its baseline.

This association is not proof that an intervention is beneficial or a chemical mechanism is established. The web protocol is fixed and differs from the desktop repeated-split workflow; consult the full manual from the software overview for broader workflows.

Troubleshooting

If rejected, inspect target spelling, numeric cells, duplicate identifiers and sample count. No API key is required for this fixed modeling route.

A completed run does not establish dataset quality, transferability or causal interpretation. Save your files before the 72-hour expiry.
