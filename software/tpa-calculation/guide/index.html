Two-photon absorption · Online guide

Submit matching fchk + TD log files, then compare one- and two-photon theoretical spectra in the browser.

Free online experienceSoftware overview

Screenshots use public teaching data or synthetic examples, without user accounts, task tokens or private research data. Select an image to enlarge it.

1. Access and task lifecycle

Sign in with an approved account. For a new account, register and verify your email; the owner must approve the application before computation is enabled.

All tools share per-account limits: one running task, two queued tasks and ten submissions per day. Results expire after 72 hours. Save results you need to keep.

2. Prepare matching Gaussian outputs

Upload one formatted checkpoint (.fchk ≤64 MiB) and one completed TD log (.log/.out ≤16 MiB) from the same calculation. The Gaussian route must include IOp(9/40=4).

Supported: all-electron closed-shell singlet, 2–40 singlet excited states, ≤300 atoms and 2000 basis functions. Geometry, atom order, axes, origin and energies must match. The server does not run Gaussian or accept raw chk.

3. Run the fixed SOS workflow

Submit and wait for the queued task. Multiwfn extracts transition/permanent dipoles, followed by the finite-state sum-over-states postprocessor. The total job limit is ten minutes.

Permanent dipoles are first put on a consistent electronic basis. The ground-state reference is copied before diagonal subtraction; off-diagonal transition dipoles remain unchanged. The result records the reference audit.

4. Compare 1PA and 2PA

Use separate panels for physical units, or normalized overlay for shape comparison. Choose incident wavelength or total transition energy. For the same final state, two-photon resonance uses about twice the one-photon wavelength.

1PA is broadened oscillator-strength density (per eV), not measured absorbance. 2PA is the signed SOS cross section in GM. Changing 1PA display width does not change the 2PA calculation. State markers denote levels, not guaranteed peaks.

Inspect plots directly, select states and ranges, and optionally export the current CSV/SVG or original ZIP.

Troubleshooting

For rejected inputs, check completion, IOp setting and matching atom/geometry information. A missing one-photon spectrum is reported explicitly.

Negative SOS responses are preserved and flagged. Finite-state convergence, damping and prefactors still require scientific review. See the software overview for original SOS and Multiwfn references.
