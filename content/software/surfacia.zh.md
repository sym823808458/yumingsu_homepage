## 让分子表示保留化学意义

Surfacia 将分子表面性质转化为多层级描述符，并连接特征筛选、机器学习、SHAP 解释与候选优先级分析。它面向希望将预测结果与化学结构联系起来的研究者。

## 工作流程

- 从 SMILES 与分子结构准备开始，组织量子化学与表面分析任务。
- 提取静电势、局部离子化能等表面性质及相关描述符。
- 进行特征筛选、建模与模型解释。
- 使用 SPES 等分析模块辅助候选排序；排序结果与原始回归预测分别理解。

## 安装与使用

Python 包可通过 `pip install surfacia` 安装。运行 `surfacia --help` 查看命令；已有描述符表时，可以单独进行机器学习分析。

完整量子化学流程还依赖 xTB、Gaussian 和 Multiwfn 等外部软件，需要自行安装并满足相应许可要求。环境与版本要求请以当前手册为准。
